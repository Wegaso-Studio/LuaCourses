# 📘 Introduction au Lua & Spécialisation FiveM

Ce repository contient un cours structuré pour apprendre les bases du langage **Lua**, suivi d’une spécialisation orientée **développement FiveM**.  
L’objectif est d’offrir un parcours clair, progressif et directement applicable au développement de scripts pour GTA V/FiveM.

# 📂 Structure du cours
- **1. Bases du Lua**  
  - Syntaxe fondamentale  
  - Variables, tables, fonctions  
  - Boucles, conditions  
  - Modules & organisation du code  

- **2. Lua avancé** (arrive plus tard)
  - Métatables  
  - Environnements  
  - Patterns & manipulation de chaînes  
  - Optimisation & bonnes pratiques  

- **3. Spécialisation FiveM** (arrive plus tard) 
  - Architecture d’une resource  
  - Communication client ↔ serveur  
  - Events, callbacks, NUI  
  - Gestion des données (JSON, MySQL, oxmysql)  
  - Création de systèmes complets (UI, gameplay, services)  

---

# 🎯 Objectifs pédagogiques

- Comprendre les bases du langage Lua  
- Acquérir les réflexes nécessaires au scripting FiveM  
- Savoir structurer un resource propre et maintenable  
- Maîtriser la communication JS ↔ Lua ↔ NUI  
- Être capable de développer des systèmes complets pour un serveur FiveM

---

# 🛠 Prérequis

- Connaissances de base en développement (JS, HTML/CSS recommandé)  
- Environnement FiveM installé (server + artifacts)  
- Éditeur de code (VS Code conseillé)  

---

# 🚀 Démarrer

1. Cloner le repository (si vous le souhaitez)
2. Suivre les modules dans l’ordre
3. Tester chaque exercice dans un resource dédié [tools-online lua](https://www.tools-online.app/tools/lua)
4. Passer à la section FiveM une fois les bases Lua maîtrisées
